# 🎓 Student Grade Calculator

A simple Python program that calculates a student's percentage, grade, and pass/fail status using functions.

## 🚀 Features

* Takes student name as input
* Accepts marks for multiple subjects
* Calculates total percentage
* Determines the student's grade
* Displays pass/fail status
* Uses Python functions for better code organization

## 🛠️ Technologies Used

* Python
* Functions
* Lists
* Loops
* Conditional Statements

## 📚 Subjects

The program currently accepts marks for:

* Python
* DSA
* DBMS
* Mathematics
* Computer Networks

## ▶️ How to Run

1. Make sure Python is installed on your system.
2. Clone this repository:

```bash
git clone https://github.com/your-username/student-grade-calculator.git
```

3. Open the project folder:

```bash
cd student-grade-calculator
```

4. Run the program:

```bash
python student_grade_calculator.py
```
